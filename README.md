# takaya-hp

株式会社タカヤ（takayagroup.co.jp）コーポレートサイト リニューアルのリポジトリ。

現行サイトは Google サイトで構築されているが、**新サイトは Google サイトでは作らない**。
テーマ色の選択しかできず、ヒーロー・カード・数値実績といった作り込みができないため、
独自実装に切り替える。ドメイン `takayagroup.co.jp` はそのまま引き継ぐ。

## 設計書

作り始める前に、この 4 つを埋める。上から順に決まっていく構成になっている。

| # | ドキュメント | 何を決めるか | 状態 |
|---|---|---|---|
| 01 | [コンセプト設計書](docs/01-concept.md) | 誰に・何を・どう言うか | 雛形（一部記入済み） |
| 02 | [サイト構成・ページ設計書](docs/02-site-structure.md) | どんなページを・どういう順で見せるか | 雛形（一部記入済み） |
| 03 | [デザインシステム](docs/03-design-system.md) | 色・文字・部品のルール | 雛形（一部記入済み） |
| 04 | [技術構成・運用・移行計画](docs/04-tech-and-ops.md) | 何で作り・誰が更新し・どう移すか | 雛形（一部記入済み） |

`【要記入】` はタカヤさん側で埋めていただく箇所、`【要確認】` は事実確認が必要な箇所。
現行サイトから確認が取れている内容はすでに書き込んである。

## 記法のルール

- 決定した事項は「決定」欄に日付を入れる。決めた日が分かると後から揉めない
- 見送った案も消さずに「見送り案」として残す。同じ議論を二度しないため
- 数値（実績・料金・電話番号）は必ず一次情報を確認してから書く。推測値は書かない

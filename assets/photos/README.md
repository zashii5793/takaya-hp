# 写真の差し替え方

**いまサイトに載っている写真が、このフォルダに「枠名.jpg」で入っています。**
同じ名前のファイルで上書きすれば、その枠の写真が差し替わります（png / webp でも可）。

GitHub 上での手順：このフォルダ（`assets/photos/`）を開く → 右上「Add file」→「Upload files」
→ 差し替えたい写真を **同じファイル名にして** ドラッグ → 「Commit changes」。
同じ名前なら自動で上書きされます。アップロード後、こちらで `site/` を再生成して反映します。

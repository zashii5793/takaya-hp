## お願い

- 上の切り出しは解像度が低い（横 200〜600px）。**パンフレットに使った元写真（JPG）**があれば、同じファイル名で置き換えるだけで画質が上がる（B-06）
- リース・ドライブのイメージ写真は未受領。現在はイラスト `site/assets/img/drive.svg` で代用（B-07）
- 追加の写真は、このフォルダに直接アップロードするか、Google ドライブの共有リンクで

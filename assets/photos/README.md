# 写真の差し替え方

**このフォルダに「枠名.jpg」を置くだけ**で、サイトのその枠がその写真に差し替わります。
（png / webp でも可。ファイル名は下の表の枠名に合わせてください。大文字小文字は小文字で）

置いたあと、開発側で `python3 tools/build_site.py` を実行して `site/` を再生成します
（GitHub にアップロードしていただければ、こちらで定期的に確認して反映します）。

GitHub 上でのアップロード手順：このフォルダ（`assets/photos/`）を開く → 右上「Add file」→「Upload files」
→ ファイルをドラッグ → 「Commit changes」。

- 横長（およそ 16:10）で撮ったものが収まりがよいです。縦横比が違っても中央を切り抜いて表示します
- 1枚 2MB 以下が目安（スマホ写真はそのままで大丈夫です）
- 差し替えたい枠だけ置けばOK。置いていない枠はパンフレットの切り出し → イメージ図の順で表示します

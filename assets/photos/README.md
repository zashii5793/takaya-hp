## 受領済み写真の内容メモ（2026-09-04）

**フロント社屋の外観**
白×紺の2階建て。大きなガラスの入口。左側の壁に「指定自動車整備事業」「自動車特定整備事業」等の看板、
右上に「ISO14001認証取得」の掲示。ヒーローに使うと横長にトリミングできる。

**整備工場**
3ベイのオープンな工場。リフトに車両。「45分 ニュースマイル車検 実施中!!」「納得の情報提供車検」の縦看板、
「60分指定整備検査ライン」「45分車検ライン」「完成検査場」の表示。
→ 自社の検査ラインを持つ指定工場であることが写真で伝わる。車検の訴求に使う。

## お願い

チャットに貼った画像は開発環境にファイルとして届きません。
**ファイル添付（jpg/png）**でお送りいただくか、Google ドライブ等の共有リンクをいただければ、
このフォルダに保存してサイトに組み込みます。

## 形式

- 掲載時は WebP に変換（元データは JPG のまま保管）
- 横 1600px 以上を推奨（ヒーローは 2000px 以上あると安心）

## 4. コンセプト

### 4-1. サイトのコンセプト（社内向けの一文）

このサイトは何であるか、を作り手が共有するための文。訪問者には見せない。

> 【要記入：例「創業60年の技術と、大手にはできない小回りを、目に見える形にするサイト」】

### 4-2. キャッチコピー（訪問者に見せる文）

| 位置 | 案 | 決定 |
|---|---|---|
| ヒーロー主見出し | 車のことは、ぜんぶタカヤで。 | 【要記入】 |
| ヒーロー副見出し | 【要記入】 | |
| 代替案 | 【要記入】 | |

**主見出しの条件**（案を評価するときの基準）

- 15文字前後で、声に出して読める
- 業種が分かる（「車」が入っている）
- 他社が同じことを言えない、または言っていない
- 中で証明できる（下のセクションで裏が取れる主張になっている）

### 4-3. 3つの約束

ヒーロー横のカードに出す、短い約束。事実で裏が取れるものだけを書く。

| # | 約束 | 裏付け | 確認状況 |
|---|---|---|---|
| 1 | 無料代車 | 代車0円 | 確認済み |
| 2 | 自社完結 | 【要確認：範囲】 | 要確認 |
| 3 | 引取・納車 | 対応 | 確認済み |

> 3つとも「他社がやっていないこと」であるか確認する。全社がやっていることを約束にすると効かない。

## 5. トーン＆マナー

### 5-1. 言葉づかい

| 項目 | 決定 |
|---|---|
| 語尾 | です・ます（統一） |
| 一人称 | 【要記入：当社／タカヤ／私たち】 |
| お客様の呼び方 | 【要記入：お客様／お客さま】 |
| 専門用語 | 使う場合は必ず言い換えを添える |
| 誇張表現 | 「地域No.1」「最安」など根拠を示せない表現は使わない |

### 5-2. 避ける表現

- 純赤 `#ff0000` の本文（読みづらい。→ 03-design-system.md 参照）
- 「〜させていただきます」の多用
- 【要記入】

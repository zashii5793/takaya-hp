# 07 アクセス・インプレッション改善の記録

タカヤHP（www.takayagroup.co.jp）のアクセス数と検索での表示回数（インプレッション）を増やすための改修を、回ごとに記録する。
**目的・背景・やったこと・測り方・次にやること**を毎回残し、何が効いたかを後から確かめられるようにする。

- 新しい回は上に足す（最新が先頭）
- 数値は Search Console と GA4（G-C4JD5FKNVN）から取る。推測値は書かない
- 決定はバックログ（[05-backlog.md](05-backlog.md)）の決定履歴にも書く

## 方針（2026-10-28 時点）

1. **検索の入口を増やす**：記事を続けて出す。整備・仕組みの解説は十分にあるので、**費用・依頼に直結する話題**（車検費用・板金の費用・下取り）と**季節の話題**を優先する
2. **記事の評価をHPに集める**：記事の正はHPの記事ページ（`/blog/<記事名>.html`）。Blogger は投稿の道具として使い、検索には載せない
3. **来た人をサービスへ送る**：記事 → サービスページ（料金表）→ 電話・お問い合わせ、の道を切らさない
4. **測ってから次を決める**：Search Console で「どの言葉で、何回表示され、何回クリックされたか」を見て、次の記事と改修を選ぶ

## 第1回 2026-10-28　記事の検索結果タイトル・記事からサービスへの導線・サイトマップ・追加記事5本

### 背景

- Blogger に記事が167本あり（2024-10〜）、毎朝の自動取り込みでHPにも記事ページができている。SEOの基本（canonical・OGP・構造化データ・GA4・関連記事）は 2026-09 に実装済み（D-19・D-21）
- 一方で、次の4点が残っていた
  - 記事の題名の末尾に「.vol169」や「#タカヤモーター株式会社」が付いており、検索結果のタイトル（30字前後で切れる）で社名の表示を押し出していた
  - 記事を読んだ人をサービスページへ送る案内が無かった（記事の下は電話・問い合わせと、同じ分類の記事だけ）
  - サイトマップの更新日が全ページ「2026-09-11」で固定。新しい記事を検索エンジンが拾いにくい
  - 同じ本文が Blogger（takayagroup.blogspot.com）とHPの両方にあり、検索エンジンがどちらを採るか定まらない
- 記事の傾向を分類ごとに数えると、整備・メンテナンス36本、仕組み23本、保険・制度19本と解説記事が厚い。**車検費用・板金の費用・下取りといった、依頼の直前に調べられる話題の記事は0本**だった
- 2026年は8月に投稿を再開したばかり（2024年69本、2025年88本、2026年10本）

### やったこと

#### HP（PR #22、ブランチ `claude/seo-blog-titles-links`）

| 内容 | 意図 | 場所 |
|---|---|---|
| 記事の `<title>`・OGP・構造化データの headline から「.vol番号」とその後ろ（ハッシュタグ・注記）を外す。記事の見出しと一覧の表示はブログの題名のまま | 検索結果で記事の中身と社名を読ませる。クリック率を上げる | `tools/build_site.py` の `search_title()` |
| 記事の下に「この記事に関連するサービス」を出す。題名の言葉 → 分類の順で決める（車検の記事 → 車検の料金表、ぶつけた・洗車 → 板金・コーティング、リース・残クレ → リース など）。整備士・業界の記事は採用情報へ。道路標識・免許など合うサービスが無い記事には出さない | 検索で来た人を、料金と申し込みのあるページへ送る | `POST_SERVICE_WORDS`・`POST_SERVICE_BY_CAT`・`service_html()`、CSS は `.post-service` |
| サイトマップの更新日を記事ごとの更新日にする。お知らせ一覧は最新記事の日付。構造化データに `dateModified` を追加 | 新しい記事・直した記事を検索エンジンに早く拾わせる | `build_seo_files()` |

振り分けの結果（記事ページ168）：車検・点検・整備 94／おクルマ探し 27／自動車保険 14／採用情報 14／板金・コーティング 7／リース 4／案内なし 8。

### 決めたこと

- **記事の正はHPの記事ページとする**（バックログ A-65 → 決定）。Blogger 側は検索に載せない（A-78）
- ただし **Search Console でHPの記事が検索に載ったのを確かめてから** Blogger を noindex にする。順番を逆にすると、一時的にどちらも検索に出なくなる

### 測り方

- 比べる数字：Search Console の表示回数・クリック数・平均掲載順位（サイト全体／`/blog/` 配下）、GA4 の記事ページの閲覧数と、記事 → サービスページへの移動
- **Search Console が未登録のため、今回の改修前の数字（基準値）は取れていない**（A-72）。登録した日を基準日とし、4週間ごとに比べる

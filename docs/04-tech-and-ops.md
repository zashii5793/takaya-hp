## 5. ドメイン切り替え

**切り替えは平日の午前中に行う。** 夜間・週末に問題が起きると誰も対応できない。

手順：

1. 新サイトを仮URL（`*.pages.dev` 等）で公開し、全ページを確認
2. メールの MX レコードを控える（**ここを壊すと会社のメールが止まる。最重要**）
3. DNS の A / CNAME を新サイトへ変更。MX は触らない
4. SSL証明書の発行を確認（数分〜数十分）
5. 主要ページ・リダイレクト・フォーム送信・電話リンクを実機で確認
6. Search Console に新しいサイトマップを送信
7. 旧サイト（Google サイト）は**すぐ消さず**、1ヶ月は残す

|---|---|
| ドメイン管理会社 | 【要記入】 |

| メールの利用状況 | 【要確認：独自ドメインメールを使っているか】 |

> ドメイン・DNS のログイン情報が分からない、が実務で一番詰まる箇所。着手前に確認しておく。

# 02. サイト構成・ページ設計書

> このドキュメントで決めること：**どんなページを作り、トップで何をどの順に見せるか。**

最終更新：【要記入 YYYY-MM-DD】

---

## 1. サイトマップ

```
/                        トップ
├── /about               会社案内（ごあいさつ・沿革・経営理念）
├── /service             サービス一覧（8業務）
│   ├── /service/xxxxx   個別サービス【要記入：どれを独立ページにするか】
│   └── ...
├── /reason              選ばれる理由            【要検討：トップ内で足りるか】
├── /blog                ブログ一覧（161本）
│   ├── /blog/[slug]     記事詳細
│   └── /blog/category/  カテゴリ別一覧          【要検討】
├── /recruit             採用                    【要検討：必要か】
├── /contact             お問い合わせ
├── /privacy             プライバシーポリシー     ※フォーム設置なら必須
└── /sitemap.xml         サイトマップXML
```

**判断のしかた**：独立ページを作るのは「そのページ単体で検索されうる」か「他所からリンクを貼りたい」場合だけ。
それ以外はトップまたは一覧ページ内のセクションで足りる。ページ数を増やすほど更新されなくなる。

| ページ | 作る／作らない | 理由 |
|---|---|---|
| /reason | 【要記入】 | |
| /recruit | 【要記入】 | |
| 個別サービスページ | 【要記入】 | |

## 3. トップページの構成

上から順に。**各セクションは「訪問者の頭の中の質問」に一つずつ答える形**で並べる。

| # | セクション | 答える質問 | 内容 | 状態 |
|---|---|---|---|---|
| 1 | ヒーロー | ここは何屋か | 赤ベタ＋主見出し「車のことは、ぜんぶタカヤで。」／白カードで3つの約束（無料代車・自社完結・引取納車） | 案あり |
| 2 | 実績の数字 | 信用できるのか | 1965年創業／8業務／代車0円／記事161本 | 案あり |
| 3 | サービス | 何を頼めるのか | 主要4業務をカードで。ホバーで赤線 | 案あり |
| 4 | 選ばれる理由 | なぜ他社でなくここか | 赤ベタ面「大手にはできないことを、やっています。」 | 案あり |
| 5 | ごあいさつ | 誰がやっているのか | 代表あいさつ＋顔写真 | 写真【要手配】 |
| 6 | 経営理念 | 何を大事にしているのか | 3枚のカード＋原文は折りたたみ | 案あり |
| 7 | ブログ | 生きているサイトか | 最新3〜4記事 | 案あり |
| 8 | 連絡先 | どう連絡するか | 赤ベタにフリーダイヤルを大きく／地図／営業時間 | 案あり |

## 4. 下層ページの要件

| ページ | 必須要素 | 備考 |
|---|---|---|
| 会社案内 | 会社概要表（商号・所在地・代表者・設立・資本金・従業員数・事業内容・許可番号）／沿革／経営理念／代表あいさつ | 取引先が見る。表の抜けは信用に響く |
| サービス | 業務内容／料金の目安【要記入：出すか】／流れ／よくある質問／問い合わせ導線 | 料金を出さない場合は「お見積り無料」等で代替 |
| ブログ一覧 | 記事一覧／ページ送り／カテゴリ絞り込み【要検討】 | 161本あるため一覧の設計は要注意 |
| 記事詳細 | 本文／公開日／関連記事／問い合わせ導線 | 記事から問い合わせに繋ぐ導線を必ず入れる |
| お問い合わせ | 電話番号／フォーム／営業時間／地図／アクセス | フォーム項目は下記 |

### お問い合わせフォームの項目

| 項目 | 必須 | 形式 |
|---|---|---|
| お名前 | 必須 | テキスト |
| 電話番号 | 【要記入】 | テキスト |
| メールアドレス | 【要記入】 | メール |
| 車種・年式 | 任意 | テキスト |
| ご相談内容 | 必須 | 選択（車検／修理／板金／購入／保険／その他） |
| 本文 | 必須 | 複数行 |
| 個人情報の取り扱い同意 | 必須 | チェックボックス＋プライバシーポリシーへのリンク |

- 送信先メールアドレス：【要記入】
- 自動返信メールを出すか：【要記入】
- 迷惑メール対策：【要記入：reCAPTCHA など】

## 6. 法令・表示義務のチェック

事業内容によって表示義務があるものを確認する。**該当するのに書いていないと行政指導の対象になりうる。**

| 項目 | 該当するか | 表示場所 |
|---|---|---|
| 自動車分解整備事業の認証／指定番号 | 【要確認】 | フッター・会社案内 |
| 古物商許可番号（中古車売買を行う場合） | 【要確認】 | フッター・会社案内 |
| 損害保険代理店の登録（保険を扱う場合） | 【要確認】 | 該当ページ |
| 個人情報の取り扱い（フォーム設置時） | 該当 | プライバシーポリシー |
| 料金表示の根拠（「無料」「◯円〜」の条件） | 【要確認】 | 各サービスページ |

## 7. 対応環境

| 項目 | 方針 |
|---|---|
| 画面幅 | スマートフォン（375px）を基準に設計し、PC（1280px）に広げる |
| ブラウザ | Chrome / Safari / Edge の最新版。Internet Explorer は非対応 |
| 表示速度 | 主要な画像は WebP。トップの初回表示 2 秒以内を目安 |
| アクセシビリティ | 本文の文字色とのコントラスト比 4.5:1 以上／画像に代替テキスト／キーボード操作可能 |

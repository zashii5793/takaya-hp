# Googleブログ（Blogger）とお知らせの連携

記事は Blogger に書き、タカヤHPに出す。出し方は2通りあり、**両方とも入っている**。

## 1. 画面で読み込む（既定・自動）

`site/assets/js/blog-feed.js` が、ページを開いたときに Blogger から記事を読んで並べる。

- トップのお知らせ 3件／お知らせ一覧 10件
- **新しい記事を書けば、何もしなくても自動で出る**
- 記事の題名をクリックすると **Blogger の記事** が開く（本文はブログ側にある）
- 読み込めないときは「お知らせは準備中です。」に切り替わる

## 2. 記事ページをタカヤHPに作る（取り込み方式）

`tools/fetch_blog.py` で記事を取り込み、`tools/build_site.py` が **タカヤHP側の記事ページ** を作る。

```
python3 tools/fetch_blog.py      # Blogger から記事を取り込む
python3 tools/build_site.py      # 記事ページを作る
site/ をサーバーへアップロード
```

- `https://www.takayagroup.co.jp/blog/<記事名>.html` という**自社ドメインの記事ページ**ができる
- サイトマップにも入り、記事ごとに title・description・構造化データ（BlogPosting）が付く
- **記事のSEOが自社サイトに乗る**
- 本文は安全な形に整えてから出す（広告・計測の指定・iframe・script は取り除く。見出しは h2 から）
- Blogger 側で消した記事のページは、次のビルドで自動的に消える
- **新しい記事は、取り込み直してアップロードするまで出ない**

### 切り替わり方

`assets/blog/posts.json` に取り込みぶんがあれば **2**（サイト内の記事ページ）、
空なら **1**（画面で読み込む）。`build_site.py` の実行時にどちらかを表示する。

## どちらを使うか

| | 1. 画面で読み込む | 2. 取り込んで記事ページを作る |
|---|---|---|
| 新しい記事 | 自動で出る | 取り込み＋アップロードが要る |
| 本文の場所 | Blogger | **タカヤHP** |
| 検索・AIに効くのは | Blogger 側 | **タカヤHP 側** |
| 手間 | なし | 記事を書いたあと3ステップ |

集客を目的にするなら **2**。記事の評価が自社ドメインに貯まる。

## 注意：同じ本文が2か所に出る

2 を使うと、同じ本文が Blogger とタカヤHPの両方に出る。検索エンジンはどちらか一方を選ぶ。
自社サイトに寄せたいなら、移行後は次のどちらかにする。

- Blogger のブログを**非公開**にして、原稿置き場として使う
- Blogger に**独自ドメイン**（例 blog.takayagroup.co.jp）を割り当て、そちらに寄せる

## 画像について

記事の画像は Blogger のアドレス（blogger.googleusercontent.com）のまま読み込む。
Blogger 側で画像を消すと、タカヤHPの記事でも表示されなくなる。

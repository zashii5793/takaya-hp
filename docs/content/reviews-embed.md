# 口コミ収集サービス（reviews.aiobridge.jp）の取り込み

## どの方式を選んだか

提供元が示した4つの方式のうち、**ビルド時に取り込んでHTMLとして書き出す方式**（提供元の説明では「④ 生成スクリプト」に相当するもの）を、当サイトの作りに合わせて自前で実装した。

| 方式 | 採否 | 理由 |
|---|---|---|
| ① サーバー側で読み込む | × | 当サイトは静的HTML。PHPやNext.jsのように、表示のたびにサーバーでページを組み立てる作りではない |
| ② HTMLを貼り付ける | × | 口コミが増えるたびに手で貼り直す必要があり、貼り忘れが起きる |
| ③ 埋め込みタグ | × | JavaScriptで口コミを出すため、JavaScriptを動かさないAIの巡回ロボットには中身が見えない。提供元も「AI対策が目的なら①②④を」と書いている |
| **④ 相当（ビルド時に取り込む）** | **○** | HTMLとして本文に書き出されるので、検索にもAIにも読まれる。取り込みは1コマンドで済む |

## 使い方

口コミが増えたら、インターネットに出られる端末で次を実行する。

```
python3 tools/fetch_reviews.py     # 口コミを取り込む
python3 tools/build_site.py        # サイトを作り直す
# site/ をサーバーへアップロード
```

- 取り込んだ内容は `assets/reviews/embed.html` に保存される
- 公開済みの口コミが0件のあいだは、口コミの節そのものを出さない（空の枠を見せない）
- 取り込みに失敗しても、前回ぶんがそのまま使われる

## 掲載場所

トップページの「お客様の声」（Googleの口コミの抜粋）の**下**に、「いただいた口コミ」として出す。
投稿ページ（http://reviews.aiobridge.jp/c/takaya-group ）へのリンクを添えている。

## 注意：Google の検索結果には星は出ない

このサービスは「構造化データに入れて、どのページの口コミかをAIに伝えます」と説明している。
取り込んだHTMLに `Review` / `AggregateRating` の構造化データが含まれる場合、
`tools/fetch_reviews.py` が実行時に知らせる。

自社サイトに自社の評価を出すマークアップは、Googleの検索結果では星の表示に使われない
（自作自演の口コミとみなされる方針のため）。**AIに読ませる目的では有効だが、
Google対策としては効かない。**当サイトは以前からこの方針で、Review/AggregateRating の
構造化データを自前では出していない。
